# Capability Specification: Social Media Preview Richness

## Requirement: Open Graph Visual Preview Metadata

The page layout MUST output complete, absolute Open Graph image metadata tags to ensure high-fidelity visual card rendering when shared on compliant platforms (e.g., WhatsApp, Facebook, LinkedIn).

### Scenario: Page share on Open Graph compliant platforms
- **Given** any rendered HTML page generated by Astro
- **When** the HTML `<head>` is inspected for Open Graph image tags
- **Then** the page MUST contain `<meta property="og:image">` pointing to an absolute HTTPS URL
- **And** the page MUST contain `<meta property="og:image:width" content="1200">`
- **And** the page MUST contain `<meta property="og:image:height" content="630">`
- **And** the page MUST contain `<meta property="og:image:alt">` providing descriptive alt text for visual accessibility and brand representation.

## Requirement: Twitter Card Visual Image Metadata

The page layout MUST supply Twitter Card visual metadata configured for large visual media display.

### Scenario: Page share on X / Twitter platforms
- **Given** any rendered HTML page generated by Astro
- **When** Twitter Card tags in the HTML `<head>` are evaluated
- **Then** the page MUST contain `<meta name="twitter:card" content="summary_large_image">`
- **And** the page MUST contain `<meta name="twitter:image">` pointing to an absolute HTTPS URL matching the Open Graph image URL
- **And** the page SHOULD contain `<meta name="twitter:image:alt">` matching the Open Graph image alt property.

## Requirement: Static Visual Preview Asset Provisioning

The application MUST provide a high-resolution, static visual preview image asset at the root public directory to serve as the default social card.

### Scenario: Default social preview image availability
- **Given** the public web server directory `public/`
- **When** HTTP GET requests are issued for `/og-image.jpg` or during production build validation
- **Then** `public/og-image.jpg` MUST exist as a valid JPEG image
- **And** the image dimensions MUST be exactly 1200 pixels in width by 630 pixels in height
- **And** the image file size SHOULD be optimized below 250 KB for fast social preview fetching.
